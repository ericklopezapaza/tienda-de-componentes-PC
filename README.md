
Descripcion del proyecto

El presente proyecto muestra la funcionalidad de una tienda de productos de computadora siendo tanto los materiales o partes de la misma
como tambien los perifericos para el equipo, usando un carrito de compra en forma de burbuja que es capaz de moverse junto al usuario mientras revisa el catalogo de los productos, tambien contiene un buscador para buscar entre las categorias disponibles.
