Descripcion del proyecto

El presente proyecto muestra la funcionalidad de una tienda de productos de computadora 
siendo tanto los materiales o partes de la misma
como tambien algunos monitores para el equipo, 
La aplicación cuenta con un catálogo que permite al usuario consultar los productos disponibles, para facilitar la búsqueda, incorpora un buscador que permite localizar productos por su nombre o descripción, además de un menú desplegable para filtrar los resultados según su categoría.
También cuenta con una sección de categorías en la página de inicio, desde la cual el usuario puede seleccionar una categoría y visualizar directamente los productos relacionados
Por otra parte, se implementó un carrito de compras representado mediante una burbuja flotante que permanece visible mientras el usuario navega por el catálogo, de esta manera, puede consultar los productos agregados y gestionar su compra sin necesidad de abandonar la página en la que se encuentra
