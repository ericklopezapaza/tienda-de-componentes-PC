Descripcion del proyecto

El presente proyecto muestra la funcionalidad de una tienda de productos de computadora 
siendo tanto los materiales o partes de la misma
como tambien algunos monitores para el equipo, 
usando un carrito de compra en forma de burbuja que es capaz de moverse junto al usuario mientras revisa el catalogo de los productos, tambien contiene un buscador para buscar entre las categorias disponibles con una opcion de filtrado por medio de un menu desplegable
que contiene las categorias, caso contrario se puede interacturar con las categorias en el inicio de la aplicacion filtrando los productos de la categoria seleccionada.
